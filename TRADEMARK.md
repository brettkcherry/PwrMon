**If you fork it, rename it.** That is the whole ask. The code is yours to build on; the
identity isn't.

## Why this exists

So that "PwrMon" means one thing. If several different builds circulate under the same name,
a bug report can't be matched to a version, a security advisory can't reach the people it's
about, and "I downloaded PwrMon and it did X" stops being a statement anyone can act on.

Keeping the name attached to one source is what makes the rest of this repository — the
changelog, the security policy, the sensor-tier documentation — mean anything to the person
reading it.

Anything else is a fork, and under the terms above should not be called PwrMon.
